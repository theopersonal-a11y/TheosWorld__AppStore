About

Pixel Forge is a pixel-art editor made for game developers and hobbyists. Draw sprites, tilesets and animations with a toolset that stays out of your way.

It is still in beta, so expect frequent updates. Project files are plain JSON next to your PNGs, so nothing is locked in.

Features

  • Layers, onion-skinning and frame-by-frame animation
  • Palette manager with Lospec palette import
  • Tile mode with seamless-wrap preview
  • Export to PNG, GIF and sprite sheets with JSON metadata
  • Pressure-sensitive tablet support
