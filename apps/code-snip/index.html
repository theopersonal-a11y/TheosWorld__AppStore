About

Code Snip is a desktop snippet manager for developers. Save the bits of code you keep googling, tag them, and find them in a keystroke with syntax highlighting for 150+ languages.

Everything is stored in a folder of plain files, so you can version it with git or sync it however you like.

Features

  • Syntax highlighting for 150+ languages
  • Tags, folders and fuzzy search
  • Multi-file snippets with descriptions
  • Export to GitHub Gist or plain files
  • Global quick-paste hotkey
