Clip Vault

A clipboard history manager that lives in your tray.

Download for Windows

About

Clip Vault remembers everything you copy so you never lose a snippet again. Press the hotkey, type a few letters, and paste. It runs silently in the tray and uses a few megabytes of memory.

Sensitive entries from password managers are ignored automatically, and you can clear history with a single click.

Features

  • Unlimited text, link and image history with instant search
  • Pinned snippets for things you paste every day
  • Global hotkey picker (default Ctrl+Shift+V)
  • Paste as plain text option
  • Optional encryption of history on disk
