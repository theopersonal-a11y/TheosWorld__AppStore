About

TheosWorld Notes is a distraction-free note-taking app built around plain Markdown files. Your notes are just text files in a folder you choose, so they work with any sync tool and never get locked in.

Version 2.0 adds a split live preview, backlinks between notes, and a command palette so you can do everything from the keyboard.

Features

  • Markdown editing with live split preview
  • Folders, tags and wiki-style [[backlinks]]
  • Instant full-text search across thousands of notes
  • Daily notes and templates
  • Notes are plain .md files — no database, no account
